# Map attribution assets

`maptiler.svg` is the official MapTiler logo from
https://api.maptiler.com/resources/logo.svg (downloaded 2026-10-07).
It is used to credit MapTiler in exported videos, including Free accounts.
Provider and source notices are also drawn into each video frame.
See https://docs.maptiler.com/guides/map-design/attribution/add-attribution/.
